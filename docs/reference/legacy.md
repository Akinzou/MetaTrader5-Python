# 2.x Broker (deprecated)

`Broker` keeps 2.x bots running and emits a `DeprecationWarning`. Several 2.x
behaviours were unsafe and changed; the [migration guide](../MIGRATION.md)
lists each one and maps the main `Broker` calls to `Trader`.
